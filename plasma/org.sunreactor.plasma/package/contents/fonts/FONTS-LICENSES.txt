Font roles (Theme.qml) and native pixel grids
---------------------------------------------

bitmap8      Press Start 2P   grid-exact only at 8, 16, 24, 32 px
bitmap_vga   unscii           grid-exact only at 16, 32 px (8x16 cells)
mono         IBM Plex Mono    vector
sans         IBM Plex Sans    vector (digits: IBM Plex Mono)
display      Orbitron         vector (body text stays IBM Plex Sans)

VT323, Geist and Sysfont are kept for skins; VT323 and Sysfont are not
grid-aligned outlines, so they are never used as bitmap fonts. Bitmap fonts are
only ever drawn through engine/BitmapText.qml (CPU rasterised 1:1); see
DESIGN.md section 4.
