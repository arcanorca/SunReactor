Font roles (Theme.qml) and native pixel grids
---------------------------------------------

bitmap8      Press Start 2P   grid-exact only at 8, 16, 24, 32 px
bitmap_vga   unscii           grid-exact only at 16, 32 px (8x16 cells)
mono         IBM Plex Mono    vector
sans         IBM Plex Sans    vector (digits: IBM Plex Mono)
display      Orbitron         vector (body text stays IBM Plex Sans)

JetBrains Mono (regular + bold) is the terminal skins' cell font
(skins/terminal/TermMetrics.qml): it covers the TUI's status glyphs
(● ○ ▲ ❯ › ━ ┈ ▁..▇) so a text run never falls back to a font with another
advance, and has a real bold for titles and values.

VT323, Geist and Sysfont are kept for skins; VT323 and Sysfont are not
grid-aligned outlines, so they are never used as bitmap fonts. Bitmap fonts are
only ever drawn through engine/BitmapText.qml (CPU rasterised 1:1); see
DESIGN.md section 4.

Instrument skins (skins/instrument/InstrumentStyle.qml) use Geist Light /
Medium / Regular / Mono and IBM Plex Sans Light / Condensed Medium / Mono for
their legend, body, data and readout roles.

Wii skin (skins/wii/) uses Nunito Regular and Bold for its rounded type: the
channel labels, numerals and sentences. Nunito is Latin-only; the skin never
asks it for other scripts.
